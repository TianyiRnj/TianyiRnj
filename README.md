## Selected Projects

### [Musashi](https://musashi.bot/) — Prediction-Market Intelligence

Turns Kalshi/Polymarket data and Twitter/X context into structured market intelligence. With collaborators, I led backend, API, infrastructure, and agent-tooling work across data ingestion, shared REST APIs, a Chrome extension, and MCP integrations.

[GitHub](https://github.com/MusashiBot) · [Chrome Extension](https://chromewebstore.google.com/detail/musashi/jjnfhhfdfeglfncccjjpojbnngodaepk)

### [Agent Run Cache](https://github.com/TianyiRnj/Agent_RunCache) — Replayable Browser Automation

A TypeScript browser automation project built on [HyperAgent](https://github.com/hyperbrowserai/HyperAgent). Records LLM-driven workflows and replays cached element actions through XPath, with model fallback when cached execution fails. Supports replay-script generation, Playwright, and Chrome DevTools Protocol.

### [MoE Text Classifier](https://github.com/TianyiRnj/moe-text-classifier) — Distributed NLP Training

Explores Mixture-of-Experts text classification with PyTorch, Hugging Face, and DeepSpeed, including distributed training and inference, mixed precision, checkpointing, and selective layer freezing.
